# DermAssist

Prototype triage app for the skin lesion classifier described in
[skin-lesion-classification-isic2018](https://github.com/subarna007/skin-lesion-classification-isic2018):
seven-class probabilities, Grad-CAM maps, ABCD shape and colour measurements and similar training cases.

A research prototype, not a medical device. Do not use it to make decisions about real patients.
The hospital shown in the app is fictional.
