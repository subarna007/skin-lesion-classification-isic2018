Seven-class skin lesion classification, tested on lesions the model has never seen

A ConvNeXt-Tiny classifier for dermoscopic images, trained on HAM10000 (ISIC 2018 Task 3) with a lesion-grouped split, class-balanced sampling and a melanoma screening threshold chosen before the test set was opened. DermAssist wraps the model in a triage tool for a district hospital setting.

Method

  1. Data

    10,015 dermoscopic images in seven classes from HAM10000, the ISIC 2018 Task 3 training set.

  2. Lesion-grouped split

    Images of the same lesion stay together: about 70% train, 15% validation and 15% test, stratified by class.

  3. Training

    ImageNet-pretrained ConvNeXt-Tiny at 384 px, class-balanced sampling, rotation, crop and colour augmentation, AdamW with cosine decay.

  4. Model selection

    The epoch with the best validation balanced accuracy is kept, the official ISIC 2018 metric.

  5. Screening threshold

    A cut-off on the melanoma probability is fixed on validation data for 90% sensitivity, then applied unchanged to the test set.

  6. Evaluation and explanation

    The test set is predicted once, with flip averaging. Metrics get bootstrap intervals, and Grad-CAM is computed for the predicted class.

Limitations

  • One public dataset, mostly from European clinics and lighter skin types. Performance on patients in Nepal is unknown and needs local validation.
  • The test set is a held-out split of the same dataset, not an external or prospective clinical study.
  • Dermatofibroma and vascular lesions have only 24 and 15 test images, so their figures are uncertain.
  • The validation curve peaks early and is noisy, so a different seed could select a different epoch. Results come from a single run.
  • Grad-CAM shows which regions influenced the score; it does not prove the reasoning is clinically valid.
